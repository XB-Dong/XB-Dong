### [Classroom Annotator ↗](https://github.com/XB-Dong/classroom-annotator)

**从课堂视频，到结构化数据集。** 把视频抽帧、人工框选、AI 候选复核与多人协作串成完整的学生人头标注流程。

- **人机共作**：手动精修与 AI 预标注衔接，候选框逐项审核后再入库。
- **协作有序**：共享工作区、自动保存与草稿恢复，处理多人编辑冲突。
- **数据成集**：按批次抽帧，导出 COCO 数据集，接入后续训练流程。

`React` `TypeScript` `Konva` &nbsp; / &nbsp; `Go` `PostgreSQL` `FFmpeg` &nbsp; / &nbsp; `Python` `ONNX`

### [LLM-NHO ↗](https://github.com/TIO-Team/LLM-NHO) &nbsp; · &nbsp; 研究问道

**大模型驱动的神经–启发式大规模路径优化。** 用大模型生成启发式，结合神经求解器探索 TSP / CVRP 路径优化。

论文 **Large Language Model-Driven Neural-Heuristic Optimization for Large-Scale Routing Problems** 发表于 **IEEE Transactions on Evolutionary Computation（TEVC，SCI 一区 TOP）**，导师一作、学生二作。

`LLM` `Neural-Heuristic Optimization` `TSP` `CVRP`
